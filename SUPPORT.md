## Usage questions

Open a
[question](https://github.com/PeraltaHD4K/risansym/issues/new?template=question.md)
after checking the documentation and existing issues. Include:

- Risansym and Python versions;
- operating system;
- a minimal example;
- the observed and expected result;
- the complete exception traceback, if applicable.

Public issues are reserved for reproducible defects and actionable feature
requests. Maintainer response times are best effort.

## Security

Do not ask security-sensitive questions in public. Follow
[SECURITY.md](SECURITY.md) for private vulnerability reporting.

## Unsupported requests

The project cannot guarantee individual algorithm design, assignment solutions,
custom integrations, or support for unpublished development snapshots.
